# 手動検証チェックリスト — 2026-08-06

対象: このセッションで入れた変更のうち **機械で検証できないもの**だけを集約する。
機械で固定できた分は unit 284 / e2e 15 に入っているので、ここには**書かない**
(重複させると「どこまで自動化されているか」が読めなくなる)。

各項目は実施後 `- [ ]` を `- [x]` にし、FAIL なら理由を追記する。**勝手に PASS にしない。**

## 前提: `pnpm build` → ⟳ → 版数確認

1. **`pnpm build`** を実行する (同期フォルダへの展開まで自動で走る)。
2. `chrome://extensions` で拡張の **⟳ (更新)** を押す。`contextMenus` 権限を追加したので、
   これをしないと右クリックメニューは出ない。
3. **拡張カードの版数が上がっているか**を見る。上がっていなければ ⟳ が効いていない。

> 実績: 以前は build と同期が別コマンドで、3 日前のビルドを見せて「右クリックが出ない」と
> 報告された。**権限を追加した回は同期していないと ⟳ だけでは絶対に動かない** (manifest が古いまま)。

## A. 右クリックメニュー

- [ ] **A1. メニューが出る**: localhost または許可済みサイトで要素を右クリック。
  期待: 「この要素を検査」「この要素のソースをエディタで開く」の 2 項目が出る。
- [ ] **A2. 動作範囲外では出ない**: **未許可**の https サイトで右クリック。
  期待: 2 項目が**出ない**(出て押せると無反応になるため、出ないことが正しい)。
- [ ] **A3. 許可した瞬間に出る**: A2 のサイトで popup から「現在のサイトで有効化」→ もう一度右クリック。
  期待: 項目が出る(`permissions.onAdded` でメニューを作り直しているため、拡張の再読込は不要)。
- [ ] **A4. モード OFF から 1 アクション**: インスペクト OFF の状態で「この要素を検査」を押す。
  期待: モードが ON になり、**右クリックした要素**のバッジが出る(別の要素ではない)。
- [ ] **A5. 許可前から開いていたタブ**: 全サイト許可を付ける **前**から開いていたタブで右クリック → 「この要素を検査」。
  期待: 動く(背後で注入して再送している)。FAIL なら無反応になるので、そのタブをリロードして再確認し記録する。

## B. エディタ起動 (scheme 起動は自動検証不可)

- [ ] **B1. dev で実際に開く**: localhost の React **開発**ビルドで要素にホバー → ⌘/Ctrl+Click。
  期待: Cursor が**実際に開き**、該当ファイルの該当行にカーソルが立つ。トーストに「エディタでソースを開いています…」。
- [ ] **B2. 右クリックからも開く**: 同じ要素を右クリック → 「この要素のソースをエディタで開く」。
  期待: B1 と同じ結果(モード ON は不要)。
- [ ] **B3. production は理由が出る**: デプロイ済みサイトで ⌘/Ctrl+Click。
  期待: 何も起きないのではなく「本番サイト(公開ビルド)のため、コードへのジャンプは使えません」が出る。
- [ ] **B4. 素の DOM は理由が出る**: 非 React サイトで同じ操作。
  期待: 「この要素は React コンポーネントではないため、開くソースファイルがありません」。
- [ ] **B5. パスマッピング**: popup の「開発者向け」→ パスマッピングに `from=to` を 1 行入れ、
  ブラウザが報告するパスと手元のパスが違う環境 (Docker / リモート) で B1 を試す。
  期待: 置換後の正しいファイルが開く。
- [ ] **B6. カスタム URL**: エディタ選択を「カスタム URL…」にし、`zed://file{file}:{line}:{column}` 等を入れる。
  期待: 入力欄が現れ、保存され、そのエディタが開く。

## C. Alt+Click の描画元リスト

- [ ] **C1. パネルが出る**: dev の React ページでホバー → Alt+Click。

- [ ] **C2. 行クリックでエディタ**: パネルの行をクリック。期待: その**ファイル**が開き、パネルが閉じる。
- [ ] **C3. 空のときに理由が出る**: 素の DOM 要素 / production ページで Alt+Click。
  期待: タイトルだけの空の箱にならず、「表示できる描画元がありません…」が出る。
- [ ] **C4. Esc で閉じる**: パネルが開いている状態で Esc。期待: パネルだけ閉じ、モードは維持される。

## D. Web Components (closed shadow root)

e2e は `attachShadow` を open 強制しているため、**closed の実挙動は自動検証できない**。

- [ ] **D1. open な shadow root**: 内部要素にホバー。期待: 内部要素の値が出る(ホストの値ではない)。
- [ ] **D2. closed な shadow root**: 内部要素にホバー。期待: ホスト要素の値が出て、**ホストとして**表示される
  (内部の値をホストの値として出していない = 誤答していない)。

## E. blob: トップレベルタブ (自動検証不可)

popup を通常タブで開く e2e 方式では `tabs.query({active:true})` が popup 自身を返すため、
blob タブを対象にできない。

- [ ] **E1. URL 不明タブの導線**: 全サイト許可を付けた状態で、`URL.createObjectURL` で作った
  HTML を新規タブで開き popup を開く。
  期待: 「このタブは URL を返しません…」と出て、有効化ボタンが**押せる**。押すと検査が始まる。
  FAIL 条件: 「このページでは有効化できません」と出て諦めさせる / 押しても無反応。
