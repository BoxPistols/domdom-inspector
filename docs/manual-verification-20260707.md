# 手動検証チェックリスト — 2026-07-07

対象: デザイナー向け UI/UX 改善 (ST-1〜ST-5, commit 6f095ea) の③目視項目 +
Chrome Web Store submit の外部作業。**Claude が実行できない、人間の実機判定が必要な項目のみ**を集約する。

## 実施環境

以下の 2 面 × 2 ロケールで確認する(該当項目のみ)。

- **dev**: localhost の React 開発ビルド(`Alt+Shift+I` で即インスペクト可能)
- **production**: デプロイ済み実サイト(popup「現在のサイトで有効化」経由)
- **ロケール**: Chrome の表示言語を en / ja に切替えて両方(言語依存項目)

各項目は実施後 `- [ ]` を `- [x]` にし、FAIL なら理由を追記する。勝手に PASS にしない。

## A. 権限・導線フロー (ST-1, ST-3)

- [ ] **A1. 許可ダイアログの実表示**: 未許可の production 実サイトで popup を開き「現在のサイトで有効化」を押す。
  期待: Chrome のオリジン許可ダイアログが**実際に表示される**。許可後、リロードなしでページ内ホバー検査が動く。
  FAIL 条件: ダイアログが出ない(silent 失敗)/ 許可してもホバー検査が始まらない。
- [ ] **A2. 有効化後の自動 ON + popup クローズ**: A1 で許可した直後の挙動を確認。
  期待: インスペクトモードが自動 ON になり、popup が自動で閉じる。ページ側にトースト + 右下ピルが即時表示される。
- [ ] **A3. ツリーボタン**: popup「モード」群の「このタブでコンポーネントツリー切替」を押す。
  期待: 現在タブにコンポーネントツリーパネルが開く。
- [ ] **A4. 開発者向けの開閉状態保持**: popup の「開発者向け」details が既定で**閉じている**ことを確認 →
  開く → popup を閉じて再度開く。期待: 開いた状態が保持されている(`popupDevOpen` 永続化)。
- [ ] **A5. popup レイアウト**: popup 幅 320px で 4 群(このサイトで使う / モード / 表示設定 / 開発者向け)が崩れず、
  ボタン・select・ヒント文が折返しても読める。
- [ ] **A6. en ロケールで日本語が出ない**: Chrome 表示言語を英語にし、有効化 3 分岐を通す —
  (成功)/(許可拒否)/(http・https 以外のページで有効化試行)。
  期待: いずれの status 文言にも日本語が一切出ない(`siteUnavailable` / `permDenied` / `permError` 等が英語)。

## B. デザインバッジ表示 (ST-2, ST-4)

- [ ] **B1. カラースウォッチ実色**: production 実サイトで色を持つ要素にホバー。
  期待: 文字色・背景色チップの左に**実際の色**の小四角(スウォッチ)が表示される。rgba 半透明色も破綻しない。
- [ ] **B2. チップ折返し**: デザイン情報が多い要素にホバー。
  期待: 1 プロパティ = 1 チップで flex 折返しし、横に溢れず読める(1 行連結ではない)。
- [ ] **B3. 野良値警告の言語**: 4px グリッド外の余白を持つ要素にホバー。
  期待: offGridWarn 警告が UI 言語(en/ja)で表示され、`{label}/{values}/{grid}` の生プレースホルダが出ない。
- [ ] **B4. prodSafeMode のレイアウト**: production 実サイトでホバーし、バッジに「本番サイト(公開ビルド)」
  (en: "production build (safe mode)")が表示される状態を確認。
  期待: 新訳がバッジ 1 行埋め込みでレイアウトを崩さない(dev / production 両ページで確認)。
- [ ] **B5. hover 60fps**: 要素間をすばやくホバー移動する。
  期待: ハイライト枠・バッジ追従がカクつかず滑らか(NFR-01, 60fps 体感)。

## C. インスペクトモードピル (ST-5)

- [ ] **C1. ✕ クリックで終了**: インスペクト ON 中、右下の常設ピル「インスペクト中 — Esc で終了」の
  ✕ ボタンをクリック。期待: インスペクトモードが即 OFF(ピル + ハイライト消滅)。Esc でも同じ挙動。
- [ ] **C2. rctl と非重複**: インスペクトとレンダー可視化を同時 ON。
  期待: 右下ピルと左下のレンダー制御(rctl)が重ならない。
- [ ] **C3. ピル自身が検査対象にならない**: ピルの上にマウスを乗せる。
  期待: ピル自体がハイライト/バッジ表示の対象にならない(containsTarget で除外)。
- [ ] **C4. scroll 時の固定**: インスペクト ON 中にページを縦スクロール。
  期待: ピルが右下に固定表示され続ける(position: fixed)。

## D. ショートカット (ST-4)
