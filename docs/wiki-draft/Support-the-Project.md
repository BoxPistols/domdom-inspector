## Other ways to support

Not in a position to tip? That's completely fine. Here's what else helps:

- **Star the repo** — visibility on GitHub
- **Share with your team** — the more people use it, the more edge cases get found
- **File a bug report** — detailed reproduction steps are gold
- **Write a review** on the Chrome Web Store after it launches
