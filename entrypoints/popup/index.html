MUI Design Inspector

ショートカット: Alt+Shift+I / 解除: Esc
対象: localhost / 127.0.0.1 の開発サーバのみ。設定は自動保存されます。
使い方ヘルプ

準備: localhost で動く React アプリ (dev ビルド) を開き、上のボタンか Alt+Shift+I でインスペクトモードを ON にします。

ホバー: 要素に枠とバッジが出ます。枠の色は 青 = MUI / 緑 = 自作 / グレー = その他ライブラリ。 バッジは「コンポーネント名 (内部名 · props · ファイル:行)」です。

クリックエディタでソースの該当行を開く
Alt+クリックowner ツリー (誰が描画したか) を表示。行クリックでジャンプ
↑ / ↓親コンポーネント ⇔ 子へ選択を移動 (Card の中身から Card 本体へ等)
Escパネルを閉じる / モード解除

MUI 内部スキップ: ON だと MUI のライブラリ内部ではなく、自分の JSX (例: SurfacesPage.tsx の <Card> を書いた行) へジャンプします。

パスマッピング: クリックしてもエディタでファイルが開かない場合、 dev サーバのパスをローカルの絶対パスに変換します (例: /src=/Users/you/project/src)。

Antigravity: antigravity:// スキームで起動します。 開かない場合は「カスタム URL」で調整してください。

production ビルドのページでは名前推定のみのセーフモードになります。
