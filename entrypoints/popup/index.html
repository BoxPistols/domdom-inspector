How to use

Setup: on a deployed site, click "Enable on current site…" once — inspecting starts right away, no reload needed. On localhost dev servers it works out of the box: turn inspect mode ON with the button above or Alt+Shift+I.

Hover: an outline and badge appear. Outline color is blue = MUI / green = your code / gray = other libraries. The badge shows the design values of the element — color, background, spacing, border-radius, typography — with names resolved against your pasted design tokens.

↑ / ↓move selection to parent / child component
Escexit mode

Design tokens: paste your Figma Variables / W3C / Tokens Studio JSON above. Matched values show the token name; unmatched "rogue" values are flagged so you can spot design-system drift on any site — MUI, Tailwind, CSS Modules, or plain CSS.

Works anywhere: React apps (dev or production build) and non-React pages alike. Component names appear when React is present; design measurement never needs it.
