How to use

Setup: on a deployed site, click "Enable on current site…" once — inspecting starts right away on that page. On localhost dev servers everything works out of the box: turn inspect mode ON with the button above or its keyboard shortcut. You can also right-click any element and pick "Inspect this element".

Hover: an outline and badge appear. Outline color is blue = MUI / green = your code / gray = other libraries or plain DOM. The badge shows the design values of the element — color, background, spacing, border-radius, typography. Where a value comes from a CSS custom property, the declared variable name is shown instead of the raw value.

Design tokens: no setup. On a page built with MUI, the theme is read from its ThemeProvider automatically — matched values show the token name, and values that miss are flagged with the nearest token. On pages without a theme you still get the declared CSS variable names and the rogue-value warnings for off-grid spacing.

Works anywhere: React apps (dev or production build) and non-React pages alike. Component names appear when React is present; design measurement never needs it.

Note: values are measured while the pointer is over the element, so :hover styles are included — on buttons and links you are seeing the hover-state values, which may differ from the resting state.

準備: デプロイ済みサイトなら「現在のサイトで有効化…」を一度押すだけで、 そのページのインスペクトがすぐ始まります。localhost の開発サーバでは最初から 全部使えます (上のボタンかショートカットで ON)。要素を右クリックして 「この要素を検査」からも始められます。

デザイントークン: 設定は不要です。MUI で作られたページなら ThemeProvider のテーマを自動で読み取り、一致した値にはトークン名、 外れた値には最近傍トークン付きの野良値警告が出ます。テーマが無いページでも、宣言された CSS 変数名と、グリッド外の余白に対する野良値警告は表示されます。

どこでも動作: React アプリ (開発・本番ビルドとも) でも、React を使わないページ でも動きます。React があればコンポーネント名も表示されます (デザイン計測自体は React 不要)。

注意: 計測はカーソルを載せた状態で行うため :hover の宣言が 効いた値になります。ボタンやリンクではホバー時の値であり、静止時と異なることがあります。
