DomDom Inspector

Use on this site

For deployed/production sites, not just localhost. Grants access and starts inspecting this page immediately.
Grant once and every site works from then on — no per-site prompts, including new tabs and after a browser restart. Tabs that are already open need one reload. Revoke anytime with the same button.

Modes

Shortcut: Alt+Shift+I / Exit: Esc
Advanced
While inspecting, ⌘/Ctrl+Click an element to open its source, or use the right-click menu. Development builds only — production builds carry no source location, so the extension tells you why instead. The editor you pick must be installed; if nothing opens, the extension offers the path to copy.
Placeholders: {file} (absolute path, leading slash included), {line}, {column}.
One per line, from=to. Needed when the path the browser reports is not the path on your disk (Docker, remote dev, monorepo). The first matching prefix is replaced.
Opens chrome://extensions/shortcuts to remap Alt+Shift+I to any keys.
How to use

Setup: on a deployed site, click "Enable on current site…" once — inspecting starts right away on that page. On localhost dev servers everything works out of the box: turn inspect mode ON with the button above or its keyboard shortcut. You can also right-click any element and pick "Inspect this element".

Hover: an outline and badge appear. Outline color is blue = MUI / green = your code / gray = other libraries. The badge shows the design values of the element — color, background, spacing, border-radius, typography — with names resolved against your pasted design tokens.

↑ / ↓move selection to parent / child component
Escexit mode

Design tokens: paste your Figma Variables / W3C / Tokens Studio JSON above. Matched values show the token name; unmatched "rogue" values are flagged so you can spot design-system drift on any site — MUI, Tailwind, CSS Modules, or plain CSS.

Works anywhere: React apps (dev or production build) and non-React pages alike. Component names appear when React is present; design measurement never needs it.

デザイントークン: 上の欄に Figma Variables / W3C / Tokens Studio の JSON を 貼り付けると、一致した値にはトークン名が表示され、一致しない「野良値」には警告が付きます。 MUI / Tailwind / CSS Modules / 素の CSS を問わず、デザインシステムからの逸脱を発見できます。
