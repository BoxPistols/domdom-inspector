How to use

Setup: on a deployed site, click "Enable on current site…" once — inspecting starts right away, no reload needed. On localhost dev servers it works out of the box: turn inspect mode ON with the button above or Alt+Shift+I.

Hover: an outline and badge appear. Outline color is blue = MUI / green = your code / gray = other libraries. The badge shows "component name (internal name · props · file:line)".

Clickopen the source line in your editor
Alt+Clickshow the rendered-by tree (who rendered it); click a row to jump
↑ / ↓move selection to parent / child component
Escclose panel / exit mode

Skip MUI internals: when ON, jumps to your own JSX instead of MUI library files.

Path mappings: if clicking doesn't open the file, map the dev-server path to a local absolute path (e.g. /src=/Users/you/project/src).

Antigravity: launches via the antigravity-ide:// scheme. If it doesn't open, adjust with "Custom URL".

On production builds it falls back to a name-only safe mode.

Render visualization (Alt+Shift+R): elements that actually re-rendered flash, colored as a heatmap of re-render count (blue=few → green → yellow → red=many). Press R to record, interact, then R to stop: you get a per-component ranking with why each one re-rendered (own state / props changed / dragged along by a parent = wasted), page vitals (LCP/CLS/INP), and a "Copy AI report" button that produces a Markdown report you can paste into an AI assistant to start a tuning conversation. Timings need a dev build; counts and causes are exact even on production.

準備: デプロイ済みサイトなら「現在のサイトで有効化…」を一度押すだけで、 リロード不要でそのままインスペクトが始まります。localhost の開発サーバでは最初から 使えます (上のボタンか Alt+Shift+I で ON)。

ホバー: 要素に枠とバッジが出ます。枠の色は 青 = MUI / 緑 = 自作 / グレー = その他ライブラリ。 バッジは「コンポーネント名 (内部名 · props · ファイル:行)」です。

クリックエディタでソースの該当行を開く
Alt+クリック描画元ツリー (誰が描画したか) を表示。行クリックでジャンプ
↑ / ↓親コンポーネント ⇔ 子へ選択を移動 (Card の中身から Card 本体へ等)
Escパネルを閉じる / モード解除

MUI 内部スキップ: ON だと MUI のライブラリ内部ではなく、自分の JSX (例: SurfacesPage.tsx の <Card> を書いた行) へジャンプします。

パスマッピング: クリックしてもエディタでファイルが開かない場合、 dev サーバのパスをローカルの絶対パスに変換します (例: /src=/Users/you/project/src)。

Antigravity: antigravity-ide:// スキームで起動します。 開かない場合は「カスタム URL」で調整してください。

本番サイト (公開ビルド) では名前推定のみの簡易表示になります。

再描画の可視化 (Alt+Shift+R): 実際に再描画された要素だけが明滅します。色は 再描画回数のヒートマップ (青=少 → 緑 → 黄 → 赤=多)。 R で記録 → 操作 → R で停止すると、コンポーネント別ランキングに 再描画の原因 (自身の state / props 変化 / 親に巻き込まれた=無駄) が出ます。 ページ性能 (LCP/CLS/INP) も併記され、「AI レポートをコピー」で Markdown レポートを AI アシスタントに貼ってチューニングの対話を始められます。時間計測は開発ビルドが必要 ですが、回数と原因は本番ビルドでも正確です。
